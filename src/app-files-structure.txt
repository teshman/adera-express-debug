Key Points:

screens/ vs. components/: Screens are full pages, while components are smaller, reusable UI building blocks.

navigation/: This is where you'll configure React Navigation to define how users move between different parts of your app.

services/: This is where we strictly enforce your "no direct Firebase client-side access" rule, routing almost everything through HTTP calls to your Cloud Functions, with AuthService handling the core Firebase Authentication SDK integration.

models/: Centralized place for your TypeScript interfaces, ensuring type safety across your client and (if shared) server code.

environments/: Crucial for managing different API endpoints between development and production.
